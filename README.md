# AI4PEX WP10: Extreme Evaporation Events

Analysis scripts and existing figures exploring extreme evaporation events
(ExEvEs) and precipitation using GLEAM, FLUXCOM and MSWEP.

## Status

The inputs for the 2001–2020 Europe/Mediterranean analyses are available in
[Zenodo record 24502905](https://doi.org/10.5281/zenodo.24502905).
All active analyses completed a clean, full-data run on Linux/WSL. An
independent run on another machine and scientific review remain outstanding.
See [data notes](docs/data.md) before publishing or interpreting results.

## Contents

- `code/`: numbered Python scripts and shared path, analysis and figure helpers;
  `code/legacy/` preserves out-of-scope historical global scripts.
- `figures/`: PNGs generated by the clean 2001–2020 full-data run.
- `docs/data.md`: input names, available provenance and unresolved gaps.
- `docs/validation.md`: checks performed and reproducibility work remaining.
- `data/external/`: data access instructions; large inputs are not in Git.
- `requirements-linux-py312.lock`: tested Linux Python 3.12 package versions.
- `tests/`: small synthetic checks, not a substitute for full-data validation.

The script numbers reflect the original files' **last-modified timestamps**,
used as an approximation of creation order. They do not imply a linear
pipeline: many scripts are alternative analyses, and preprocessing outputs need
to be available as inputs to later scripts. See [workflow](docs/workflow.md).

## Setup

Use Linux or WSL with Python 3.12; several scripts explicitly use the `fork`
multiprocessing method and are not compatible with native Windows Python.
From the repository root in a Linux/WSL shell:

```bash
python3.12 -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements-linux-py312.lock
python -m pytest -q
```

The lock records one tested package set, not the original authors' environment.
Full-data performance, numerical equivalence, other platforms and downstream
dependencies are not certified. Data and redistribution licenses must be checked separately. No software
license is currently specified for this repository.

## Run

Download and verify the inputs, then create the Mediterranean FLUXCOM subset
as described in [docs/data.md](docs/data.md). Configure paths for analysis:

```bash
export EXEVES_DATA_DIR="/path/to/input-data"
export EXEVES_OUTPUT_DIR="/path/to/output"
export MPLBACKEND=Agg
python code/04_exeves_analysis.py
```

Replace the example paths with actual locations. Without these variables the
current working directory is used for both inputs and outputs, preserving
the original scripts' behavior. Output files with existing names may be
overwritten. Data-preparation scripts write NetCDF results to the output
directory; make them available in the input directory for downstream scripts.
For the complete workflow and figure checksum comparison, see
[docs/workflow.md](docs/workflow.md).

Some scripts require substantial memory and disk space. Script 07 uses a
fixed random seed of 42 for reproducible cell selection; its result need not
match the previously saved, randomly selected `cell_timeseries.png`.
The checked-in PNGs are the 2001–2020 clean-run outputs; scripts write to the
configured output directory rather than updating `figures/` automatically.
